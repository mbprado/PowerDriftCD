# 2026-10-18 U.S. 2M Word RAM round trip

**Question/hypothesis:** can the main CPU explicitly enter 2M Word RAM mode, hand the RAM to the sub-CPU, and read back two words after the sub-CPU returns it? **Expected evidence:** the memory-mode register changes from 1M to 2M, then shows sub ownership during a sub-CPU write and main ownership before the main-CPU read; the main CPU reads `$ABCD/$1234` and sets a `WR00` completion marker. **Result — verified by execution:** `PASS` in BlastEm under both owner-supplied U.S. Model 1 and Model 2 BIOS files. This is an emulator-level functional result, not a timing or physical-hardware result.

**Documented only:** Sega's [software development manual](https://segaretro.org/images/archive/6/6f/20190509144929%21Mega-CD_Software_Development_Manual.pdf) describes `$A12002` / `$FF8002` memory-mode fields: MODE selects 1M or 2M, main-side DMNA yields 2M Word RAM to the sub-CPU, and sub-side RET returns it to the main CPU. The [hardware manual](https://segaretro.org/images/5/51/Mega-CD_Hardware_Manual.pdf) covers the 2M switch, and the [technical bulletins](https://segaretro.org/images/2/2e/Sega-CD_Technical_Bulletins.pdf) list safe Word RAM address ranges. The experiment uses main `$210000/$210002` and the corresponding sub `$090000/$090002`, inside those listed ranges.

**Baseline and correction — verified by execution:** the first build assumed the BIOS had already selected 2M mode. At IP entry, both CPU debugger views showed memory-mode `$2A05`, whose low bits indicate 1M mode and RET set. Writing main-side DMNA without first switching mode left the main CPU waiting; this failed build did not exercise a 2M handoff. Its ignored raw transcript is `build/evidence/2026-10-18-us-wordram-2m/initial-1m-assumption.log`. The corrected build first sends `WM` through command slot 7 and requests INT2. The sub-CPU callback writes `$01` to `$FF8003`, selecting 2M mode with main ownership, then replies `MR`. Only after checking MODE=0 and RET=1 does the main CPU seed Word RAM. It sends `WR`, writes `$02` to `$A12003` to yield, checks RET=0, and requests INT2. The sub-CPU writes `$ABCD/$1234`, sets RET, and replies `WD`. The main CPU checks RET=1 before reading and comparing the words. The wait loops have no timeout; debugger inspection is needed if a stage stalls.
