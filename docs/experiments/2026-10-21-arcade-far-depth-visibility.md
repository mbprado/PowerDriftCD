# Phase 1B: farther arcade depth and intermittent visibility — 2026-10-21

**Question / hypothesis:** does a farther ROM-backed geometry sample remain traceable and visibly useful longer than the [nearer `$3200` sample](2026-10-21-arcade-depth-sequence-limit.md)? **Baseline:** the callback-950 owner-local MAME state, the established center/left/right steering replays, and the 960–1000 geometry/list/source/screen captures. **Acceptance:** follow one unchanged farther-depth sample through consecutive projection, list, sub-CPU-X and descriptor epochs; use one-descriptor hide interventions to check actual native-bitmap/screen contribution; include a same-value control and repeat. **Result — PASS for a longer data path, partial PASS for a visible reference, verified by execution in MAME:** the `$3A00` sample matched **30/30** selected projection → list → sub-CPU-X → descriptor epochs across ten updates and three steering conditions. It was invisible in the native bitmap and screen at the first tested epoch, then contributed intermittently, becoming a contiguous 168-pixel row-150 span in the center run near the end. It is not a continuous unoccluded edge or decoded camera trajectory.

## Controlled visibility

**Verified by execution:** at callback 994, the left-steered descriptor (`$E550`) changed 1,715 pixels on callback-995 screen, bounding box x 184–319/y 153–187, with no row-150 contribution. Steering changes both selected descriptor details and the final affine image, so the three bounding boxes do not isolate one camera control. A center same-value override at 994 left source RAM and callback-995 screen identical to baseline; a repeated hidden run reproduced both files byte-for-byte.

**Inference from verified execution:** the farther depth has a longer *traceable* lifetime than `$3200`, but visibility is phase- and steering-dependent. It provides several concrete rendering checks and one fully visible center scanline, not yet a stable multi-frame track-edge sequence. **Unsupported:** a decoded road centerline/edge, world-space units, camera pose, curve/elevation parameters, or sufficiency of the Sega CD five-word camera input. No Sega CD engine change, second arcade emulator, physical hardware test or performance measurement occurred.
