# Phase 1B: original-art width profile against three arcade updates — 2026-10-23

**Question / hypothesis:** can a modest original-art source-width profile represent the [three causally verified arcade road updates](2026-10-23-arcade-three-update-road-sample.md) more closely under the project's existing 128×64 crop, while keeping the five-word camera interface? **Baseline:** the 56/58/60-source-pixel [wide road motion fixture](2026-10-23-coupled-wide-road-motion.md). **Acceptance:** preserve the existing fixture's host geometry as a control; use the established [134–190 arcade crop and 2.5X+0.75 horizontal sample](2026-10-22-wide-host-road-fixture.md); fit the same static artwork to all three update points; decode original-art previews and check pixel bounds; hold out additional causal rows. **Result — verified by execution of host software: PASS for the three fitted rows per update, FAIL for a close width match on the three held-out screen-975 rows.** This is a geometry experiment, not a Sega CD timing or fidelity milestone.

## Held-out shape check and interpretation

**Verified by execution of the host reference:** screen 975 had three additional causal two-sided arcade rows Y=157–159 that were **not used** to choose source widths, source center or packets. With the screen-975 packet held fixed, their mapped output rows 26–28 had target widths **89, 91, 91** pixels, while the original-art host image produced **87, 87, 86** pixels. Mean absolute edge error was **1.833** output pixels per edge; mean absolute width error was **3.667** pixels per row, with a largest single edge discrepancy of **4** pixels. This fails the same approximate two-pixel width tolerance met by the fitted rows. The vertical width gradient remains incomplete even though the nine fitted row observations look close.

**Inference from verified execution:** the current five-word transport and original-art stamp approach can express a useful *approximation* to this bounded screen-space sample, but independent packet selection and a tuned static art center overfit the three measured rows. A wider row span or held-out update could expose more mismatch. The new source profile carries no measured Sega CD processing cost; the prior 30 Hz BlastEm runs apply to the older 56/58/60 artwork and synthetic packet sequence only. **Unsupported:** a predictive arcade-to-camera adapter, faithful road curvature/elevation/banking, complete track geometry, 30 Hz delivery for these three new packets in BlastEm, and stock-hardware performance.
