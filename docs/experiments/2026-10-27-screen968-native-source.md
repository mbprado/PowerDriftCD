This is a capture-window control; it does not establish equivalence beyond the exercised schedule.

**Verified by execution:** the broad callback-967 hide changed only 3,924 descriptor hide bytes, preserved screens 960–967, and changed all ten predeclared screen-968 edge RGB pixels. Under the captured **pre-966** rotation transform, all ten mapped to opaque words in native bitmap **967** before the hide and `$FFFF` transparent words afterward. The baseline native values were `$0042`–`$004A`; the recorded 16B layer was clear at all ten screen pixels. Other capture/transform combinations did not explain all ten: native-967/pre-968 explained three, native-968/pre-966 and native-968/pre-968 explained zero. Thus the source bitmap and transform timing are execution-verified for these samples. The sampled pixels still have not been proven to be the complete road contour.

**Verified by execution — planned narrowing FAIL:** the callback-967 linked list had 111 reachable descriptors, all in page `$E`; the neighboring captures showed pages `$8` at callback 966 and `$C` at 968. Hiding all **212 active page-E descriptors** at callback 967 changed only those hide bytes and preserved prior screens, but changed **0/10** screen-968 edge pixels and **0/10** mapped native words. Its entire native-967 bitmap SHA-256 equaled the baseline bitmap. Therefore the reachable page at that Lua callback is not the source of these sampled pixels in the tested render stage. **Hypothesis:** a buffered or earlier page feeds native bitmap 967; the responsible page and exact latch point are **unsupported**. Per the frozen stop rule, no other page or individual descriptor was searched.

**Decision:** broad Y-sprite/native attribution **PASS** for ten sampled pixels; page-E source hypothesis **FAIL**; exact road-descriptor attribution and arcade-to-Sega CD adapter remain **INCONCLUSIVE**. This does not change the validated scalar chain or establish a five-word camera mapping. No host preview, BlastEm, other arcade emulator, physical hardware, or timing benchmark was run. MAME execution speed is not original-hardware timing.
