# Phase 1B: bounded `$8A → $86` producer test — 2026-10-27

## Question, baseline and frozen sequence

**Hypothesis:** main-CPU instructions before `$034DA4` can predict the next shared word `$0C08C6` (`A5+$86`) from earlier state. **Baseline:** local `73668dc` on `experiment/perspective-road`, isolated MAME 0.289, owner-private callback-950 state, and the existing `$88`/`$7A` predictive tests. The [pre-target plan](2026-10-27-state86-plan.md) fixed steering pulse 216, callback markers 961, 963, …, 999, input and output PCs, arithmetic, and exact-match criterion before the target-only replay.

**Verified by execution:** the first input-only run captured **zero** hits at the initially planned `$034D04`. A separate PC-only path trace, which captured no state values, found 20 hits each at `$034D44`, `$034D56`, `$034DA0`, and `$034DA4`, and none at `$034D00/$034D04/$034D22`. The planned `$28/$30 → $8A` calculation therefore cannot be tested on this schedule. Before any target capture, the plan was amended to use pre-existing `$8A` at `$034D44`, while keeping pulse 216, the same 20 markers, and target PC `$034DA4`. Both the unsuccessful input log and PC-only path log remain private and intact.

## Prediction and result

**Verified by execution:** the corrected input-only run recorded 20 values of pre-update `$8A`, `$24`, `$80`, old `$86`, and flag byte `$91` at `$034D44`. The [Python model](../../tools/phase1b_state86_predict.py) applies the observed instruction path: retain old `$86` if `$24=0` or bit 0 of `$91` is set; otherwise negate signed `$8A`, apply the strict `(-8,+8)` zero zone, arithmetic-half if `$80` is nonzero, limit the signed step toward the desired value to half its absolute value with minimum one, and add modulo 16 bits. The read-only [MAME probe](../../tools/phase1b_mame_upstream_probe.lua) recorded only the resulting `$86` at `$034DA4` in a separate replay. The private prediction JSON was frozen with SHA-256 `2eda15c9c0aac28c74ea0617b96c3e0a29115a4f5b372ab45208fdd7057cb237` **before** that target replay.

**Verified by execution:** all **20/20 held-out `$86` values matched exactly**, with zero differences at the same callback markers. The 20 input and target events were counted independently. Across this schedule, `$8A=$007F`, `$80=0`, `$91=0`, and `$24` was nonzero (`$00E0–$00FE`); the desired signed value was −127 and the step limit was 63. The first two steps were clamped to −63, the third was −1, and the remaining 17 were zero. The predicted sequence began `$FFC1`, `$FF82`, `$FF81` and then stayed `$FF81`. This validates the exercised `$8A → $86` step, including its negative clamp and convergence. The retain, zero-zone, `$80` half, and other source-sign branches are **documented only** from local instructions and remain unvalidated dynamically. The input and target correspond to the same producer update, not a measured display-frame latency.
