# Phase 1B: `$8A` source attribution plan — 2026-10-27

**Hypothesis:** the `$0C08CA` (`A5+$8A`) value consumed at main-CPU `$034D56` is prepared at an earlier, observable write site on the pulse-216 path. **Baseline:** local `ce6a343`, isolated MAME 0.289 and private callback-950 state. The prior held-out `$86` test observed `$8A=$007F` at all 20 input events while a PC-only trace did not visit `$034D04/$034D22`, the obvious local writer. The private assembled main-CPU bytes show `$034D22` writes `$8A` on one path, but that path was not observed in the tested window.

**Discovery control:** watch only writes to shared `$0C08CA` in the main CPU's program space during callback markers 961–999, using the existing pulse 216 and logging writer PC, address and data. Do not capture `$8A`'s eventual consumer value in the writer run. Check for a writer once per marker; if there is none, inspect the value already present at callback 950 and trace its earlier source in a separate bounded run. Do not label a source solely from the local disassembly.

**Prediction gate:** only after attributing an exercised writer, select an unused pulse and freeze the writer's earlier input fields, arithmetic, target PC, callback alignment and acceptance threshold **before** a target-only replay. Require exact held-out values. If the writer is not observed, report the precise gap and stop this experiment without pretending that the already validated `$8A → $86` result predicts `$8A` itself. Keep ROMs, saved states, raw debugger output and assembled binary under ignored `build/private/`; do not change the Sega CD renderer or push.

**Discovery update, before any held-out target run — verified by execution:** the pulse-216 watch recorded 20 writes to `$0C08CA` at debugger PC `$033922`, each containing `$007F`. The private instruction bytes show that the actual preceding instruction at `$03391A` copies global `$0CE0CE` to `A0+$8A`; `$033922` is the watchpoint's post-write PC. Trace writes to `$0CE0CE` next, then select a genuinely earlier input point. A copy of an observed global value is insufficient for the upstream predictive goal.

**Frozen held-out test — hypothesis from private main-CPU bytes and documented MAME devices:** a pulse-216 source watch observed one `$0CE0CE` write at post-write PC `$037550`. The preceding `$0374D0–$03754A` code clamps the input byte `$0CFF27` to `[53,203]`, updates state words `A5+$16/+$18`, and, if the absolute accumulated change exceeds 2, multiplies `(clamped_input−128)` by 256 and uses the mapped `$084000` divider with divisor 150; the result is clamped to signed `[-127,127]`. MAME's Y-Board map and `segaic16_m.cpp` document the main-CPU multiplier at `$080000` and signed divider at `$084000`. Select previously unused pulse **176**, for which the expected non-saturated quotient is 81 if the input byte follows the injected steering. Capture only earlier `$0CFF27`, old `A5+$16`, old `A5+$18`, and old `$0CE0CE` at PC `$0374D0`; freeze one prediction per callback marker for `$0CE0CE`, then compare against target-only `$0C08CA` at PC `$033922` in a separate replay. Require 20 exact, callback-aligned values at markers 961–999. The intermediate source write may occur only once; report that separately. Do not adjust the rule after seeing targets. If input and copy are not in the same callback stage, stop and correct alignment using PC-only event order before observing target values.

**Input-point correction, before target observation — verified by execution:** the first pulse-176 input-only run at `$0374D0` with `A5==$0C0840` captured zero entries. The source writer was previously observed without an A5 condition, so that assumed register base was unjustified. Repeat the same input-only capture with an unconditional breakpoint and log the actual A5. No `$8A` target has been captured for pulse 176.
