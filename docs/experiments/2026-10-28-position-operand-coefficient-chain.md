# Phase 1B: position operand and coefficient chain — 2026-10-28

## Question and frozen test

**Hypothesis:** the adjusted `$0C0856` position can be predicted one stage earlier than the [multiplier-input model](2026-10-28-position-multiplier-heldout.md), using the pre-write operand state, a RAM-table index and a base position. **Baseline:** source revision `4686600`, callback-950 private state, pulse 204 development, isolated MAME 0.289. **Acceptance:** identify the writer and coefficient lookup, fit the exercised path on 20 development updates, freeze 20 predictions from a distinct input-only steering schedule, then compare a separate output-only run. Predict the operand, coefficient and adjusted position; report which branches were actually exercised.

## Source path and algorithm

**Verified by execution and read-only local disassembly:** main CPU PC `$034FD6` writes the operand state at `$0C0868` (`A5+$28`). The same value is read later at `$034C10` and written to the `$080000` multiplier. In the observed `$034FA4–$034FD6` path, the writer adds the low word of `D3` to `D0`, optionally adds state `A5+$7E` when `A5+$80` is positive, then clamps the signed word to `[-$05FF,+$05FF]`. The preceding `$034EF4–$034FA2` path computes `D0/D3` using state, a RAM lookup and arithmetic devices; this experiment starts at their **pre-add** values. It does not reconstruct them from steering.

**Verified by execution and read-only local disassembly:** PC `$034AF8` loads a lookup offset from shared `$0CEA04`; PC `$034AFE` reads a word from the generated main-CPU RAM table at `$1FB000 + signed16(offset)`. That word remains the low 16 bits of `D1` through `$034C02`, where it is doubled for a ROM coefficient lookup at `$000EF6 + 2×index`. The owner-private, previously [MAME-verified assembled main-CPU image](phase1b-static-analysis-feasibility.md) supplied those coefficient bytes to the independently written [chain predictor](../../tools/phase1b_position_chain_predict.py). Its SHA-256 was `03143b6e3ba0045109e1745d06e04bda0db638f1cd7fadb1eab0b403fae40618`; no ROM bytes are tracked. The predictor then applies the previously validated signed multiplier and arithmetic `>>9` position adjustment.

**Verified by execution, development pulse 204:** the focused trace found one operand write at post-write PC `$034FDA` per update. Its first `$00A7` write preceded the `$034B02` index `$0025`, ROM coefficient `$0073`, and adjusted `$17F8` result. The model matched **20/20 for each of operand, coefficient and adjusted position**, 60 fields total. The callback-1020 screenshot matched the earlier pulse-204 position-math run.

## Held-out result and limits

**Verified by execution, pulse 154 — PASS for the exercised path:** the input-only trace had no target values. Compared with development pulse 204, all 20 pre-add input rows changed, nine index rows changed and six base-position rows changed. The output directory was empty when 20 three-field predictions were frozen under SHA-256 `f6ee207613092b1743106bb2952e3fb0e6676074b0bb688ec6c43532072c8f9e`. A fresh output-only MAME run then matched **60/60 frozen fields** with zero errors: 20 operand, 20 coefficient and 20 adjusted-position values. Relative to development, all 20 operand and adjusted-position values changed; four coefficient values changed. The input-only and output-only callback-1020 images were byte-identical, SHA-256 `aaebca5979148d5c597f2856eda4b3cb14134bf875c74fd92bbd904e3addce19`.

**Important exercised-path limit:** in all 20 held-out updates, the low word of the captured pre-add `D3` was zero, `A5+$80` was not positive, and the clamp was not reached. The operand prediction therefore reduces to the already computed low word of `D0` in this window. The test verifies its write order, the coefficient lookup from the earlier index, and the full downstream position arithmetic; it does **not** validate the optional addition, nonzero correction or clamp branches. The source of `D0`, runtime source of the `$0CEA04` lookup offset, and physical meaning of the generated `$1FB000` table values are still upstream dependencies. Prior work identified the table's boot-time writer; this test did not revisit it. No steering-to-camera sequence or Sega CD packet is claimed.
