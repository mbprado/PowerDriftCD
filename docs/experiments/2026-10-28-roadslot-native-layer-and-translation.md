# Phase 1B: changed road-slot edge layer and translation source — 2026-10-28

## Question and acceptance

**Hypothesis:** the new X=291 right bound after the [controlled projection change](2026-10-28-pulse204-road-record-projection.md) is not a visible road Y-sprite edge; the road-like record's perturbed translation input can be traced at least one producer stage backward. **Baseline:** local commit `408b6f1`, callback-950 private state, pulse 204 at callback 960, and the already repeated `$0100` temporary projection-input intervention. **Acceptance:** reproduce its 23 composed screens with native-layer capture, classify both sampled sides using the native Y-bitmap and 16B layer, perform a one-record 16B hide if indicated, and observe the earlier translation write sequence. No target pixels or Sega CD camera controls were fitted.

## Native-layer result

**Verified by execution in isolated MAME 0.289:** the native-capture replay reproduced all 23 screen PNGs from the prior changed-input run. For screen 967 at Y=159–161 and screen 968 at Y=159–163, the eight left pixels map through the captured pre-966 affine block to opaque native Y-bitmap words (`$0042`–`$0045`). Hiding `$E630` or `$C630` made all eight respective native words `$FFFF` and changed all eight composed RGB pixels. This confirms those *left samples* remain causally visible Y-sprite output under the changed projection.

**Verified by execution:** all eight X=291 right pixels map to `$FFFF` in the native Y-bitmap, before and after the exact Y-descriptor hides. MAME's per-pixel composition capture classifies all eight as `16b_occluded`, with sprite pen `$02E1`. This explains why the Y-descriptor hides changed 0/8 right RGB samples. The two-sided color detector therefore does not yield a two-sided *road* measurement at this changed input. It is a measurement of composited colors, with an unrelated 16B source on the right.

**Verified by execution for screen 968:** the callback-967 B-sprite RAM has one active candidate with the sampled vertical range and `$02E0` palette base: 16-byte descriptor `$0040`. Hiding it changed exactly byte `$0044` in the source RAM, cleared the 16B layer at all five screen-968 X=291 samples, changed all five RGB pixels, and changed 1,435 RGB pixels on the screen overall. Screens 960–967 were unchanged. The same descriptor was previously attributed to a screen-980 16B feature under another pulse; this run independently verifies its screen-968 effect under pulse 204. **Unsupported for screen 967:** a hide at callback 965 or 966 did not affect screen 967, though its sampled pixels are execution-verified as 16B covered. Do not assign screen 967's exact B-sprite descriptor or latch time from this result.

## Translation input provenance

**Verified by execution:** a separate read-only pulse-204 transform/upstream trace reproduced the same callback-1020 screenshot as a trace without the extra upstream watches. In the relevant ordered main-CPU events, the base sample loaded `$17D3` into state `$0C0856`; the adjustment path wrote `$17F8` there; the transform producer read `$17F8` at PC `$03483C` and wrote its 16-bit negation `$E808` to `$0C009C`; the next selected-object `$033D1E` projection read `$E808`. The observed arithmetic is `$17D3+$0025=$17F8` and `-$17F8 mod 65536=$E808`. The memory watch reports PCs `$034AF0` and `$034C38` *after* the corresponding write instructions (`$034AEC` and `$034C34` in the locally captured MAME disassembly). The source trace and prior [upstream report](2026-10-21-arcade-upstream-state-and-matched-depth.md) establish a ROM-backed base sample plus an adjustment, but the `$0025` adjustment's upstream inputs and hardware arithmetic have not been independently predicted in this pulse. Physical coordinate meaning remains **unsupported**.

**Inference from verified execution:** the preceding run's temporary `$0100` change operated on the real `$0C009C` translation word at the selected projection entry. This strengthens the one-record causal chain from upstream state to visible *left* samples. It does not prove that steering alone predicts `$0C0856`, the full road boundary, or a five-word Sega CD camera packet.
