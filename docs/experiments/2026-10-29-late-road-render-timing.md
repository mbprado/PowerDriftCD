# Phase 1B: late Y-sprite render timing — 2026-10-29

## Question and acceptance

**Hypothesis:** callback-988 page-`$E` hides failed because the game replaced those descriptor bytes before the Y-sprite renderer read them. **Baseline:** the [late-source feasibility test](2026-10-29-late-road-source-feasibility.md), callback-950 private saved state, pulse-56 input, and unmodified screen/source captures. **Acceptance:** capture the linked list at MAME's `screen_update`, compare the native 512×512 Y-sprite bitmap and the composed screen for an early hide and a deliberately later hide, and align Lua callback labels with MAME screen-frame numbers. The later hide must change both native output and the final screen in fresh replays. This diagnostic does not identify a single road descriptor.

## Result

**Verified by execution — timing cause found:** Lua callback counter 988 occurred while `screen:frame_number()` was 986; 991 mapped to 989 and 992 to 990. The Y-sprite renderer's frame 990 followed page `$E` with 102 reachable descriptors. In the callback-988 page-wide hide trial, the 102 added hide bits were still present in source-RAM captures at callbacks 989 and 990, but were absent at callback 991. At renderer frame 990, the early-hide trial and baseline both had only one already-hidden descriptor, identical native bitmaps and identical final screens. The bytes had been replaced before this render; their exact writer was **not traced**.

**Verified by execution — corrected intervention PASS:** a fresh page-`$E` source image from callback 991 was changed only by setting word-0 hide bit `$1000` at 16-byte descriptor boundaries. The callback-991 write changed 206 bytes in the full 64 KiB RAM image; the render-point reachable-list hidden count rose from **1 to 102** at MAME frame 990. The native bitmap changed at **76,546 of 262,144 16-bit words**. The corresponding composed `swap-screen-0992.png` changed at **46,826 of 71,680 RGB pixels** (125,863 individual color channels). Render frames 988–989 and 991–995 had zero changed native words, and composed screens 960–991 and 993–1000 were unchanged. The broad hide visibly removes most of the scene's Y-sprite layer, so this establishes stage timing and visibility, **not** road-specific source attribution.

**Verified by execution:** the late hide was repeated in three fresh MAME processes and separate ignored directories. All 58 checked native-bitmap, list-summary, source-after and screenshot files were byte-identical across the three runs. The instrumented binary's unmodified pulse-56 screens 960–1000 decoded identically to the earlier uninstrumented baseline. The new capture code only reads sprite RAM and writes diagnostic files when `PDRIFT_YBITMAP_DIR` is set.

**Decision:** the late-window failure is explained by a callback/render alignment and intervening source-RAM replacement. The correct page-`$E` intervention point for this tested output is callback 991, with native renderer frame 990 and composed Lua screenshot 992. The previously nominated **screen 989** is still not a validated phase-to-road landmark; this test does not connect the independently predicted phase to any particular pixel. The Sega CD camera interface and renderer remain unchanged.
