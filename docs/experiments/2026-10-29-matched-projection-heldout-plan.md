# Pretarget plan: matched-record projection at a new steering input — 2026-10-29

The existing [fixed-point model](../../tools/phase1b_projection_replay.py) matched many observed outputs when given the correctly timed horizontal offset; this test asks whether the offset is already available at the earlier callback. A failure would identify a temporal dependency, not invalidate the arithmetic model.
