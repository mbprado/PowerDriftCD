# Pretarget plan: matched-record projection at a new steering input — 2026-10-29

**Hypothesis:** the main-CPU projection for geometry object `$0C1D00` can be predicted one update ahead from a callback-988 input snapshot. The [matched-record result](2026-10-29-matched-late-road-record.md) established that this object carries one ROM-backed sample through the shared list to visible graphics under two other steering schedules. The existing [fixed-point model](../../tools/phase1b_projection_replay.py) matched many observed outputs when given the correctly timed horizontal offset; this test asks whether the offset is already available at the earlier callback. A failure would identify a temporal dependency, not invalidate the arithmetic model.

**Frozen schedule and target:** load the private callback-950 state, hold the established coin/start/pedal sequence, apply steering pulse **88** at callback 960, and predict the raw `projected4/projected6` words of object `$0C1D00` at callback **990**. Pulse 88 was not used in the existing projection-model validation. The input run may capture only callback-960–988 geometry rows; at callback 988 it also captures `$0C00AE` (the known horizontal-offset source) and the old `$0C0098`. The predictor reads only those files. Its calculation is `project(callback_988_object_row, callback_988_$0C00AE)` with unchanged signed fixed-point arithmetic and table coefficients. No target projection word, later global packet or target screenshot may be used to choose the predicted values.

**Sequence:** (1) freeze this plan and the capture/predictor code; (2) run one input-only MAME replay with `PDRIFT_SEQUENCE_END_FRAME=988 PDRIFT_GEOMETRY_SAMPLE_DIR=. PDRIFT_PROJECTION_INPUT_DIR=. PDRIFT_PROJECTION_INPUT_FRAME=988 PDRIFT_STEER_PULSE=88`, leaving all source overrides disabled; (3) write an ignored prediction JSON with `tools/phase1b_matched_projection_predict.py freeze` and record its SHA-256 before opening a target output; (4) run three fresh, separate target-only MAME replays through callback 990 with geometry capture and no projection-input capture; (5) validate the frozen X/Y words against each run and report exact signed word differences. A target run must execute MAME; cache hits do not count as repetitions.

**Acceptance:** the input CSV ends at callback 988 and contains one `$0C1D00` row; the offset snapshot is exactly at callback 988; the prediction file and its input hashes are frozen before the first target run; all three independent target runs agree; and both predicted 16-bit output words match exactly. If the prediction fails, trace only whether `$0C00AE` changes between callback 988 and the marker-989 projection entry, then report the precise blocker. Do not fit an offset from callback-990 output.

**Scope:** a pass would predict one stage-local arcade projection from earlier emulated state. It would **not** predict the offset from steering alone, establish a complete camera model, calibrate screen pixels, or justify a Sega CD renderer change. All ROMs, saved states, raw captures and target logs stay ignored under `build/private/`. This is MAME-only work; no physical hardware test or push is authorized by this plan.
