# Phase 1B: upstream offset-source prediction — pretarget checkpoint

**Hypothesis:** the main-CPU write to `$0C00AE` can be predicted from the earlier position-chain operand and lookup index, then used to predict object `$0C1D00`'s next projection. **Baseline:** the [held-out matched projection](2026-10-29-matched-projection-heldout-result.md) predicted X/Y only after reading `$0C00AE` at callback 988. This test does not read that word in its input capture. **Acceptance:** exact offset-source write at marker 987 and exact X/Y words at callback 990 in one separate pulse-92 target run. The earlier source model's five available pulse-204 writes must match before freezing.

**Verified by execution and local disassembly:** `$034C20–$034C44` uses the same operand as the position adjustment, but selects the coefficient at main-CPU ROM address `$000CF6 + 2×index`. Signed 16-bit operand and coefficient are multiplied; the 32-bit product is arithmetically shifted right nine bits, then its low 16 bits are arithmetically shifted right four bits. `$034C44` writes that word to `$0C00AE`. The [predictor](../../tools/phase1b_offset_source_predict.py) matched **5/5** source writes in an existing pulse-204 focused trace. That trace covers only markers 961–969; it is a development check, not the held-out result. The earlier [position-chain model](../../tools/phase1b_position_chain_predict.py) supplies the operand from the pre-add state, and the existing [projection model](../../tools/phase1b_projection_replay.py) supplies X/Y.

**Pretarget checkpoint — verified by execution:** an input-only MAME run using pulse 92 stopped geometry capture at callback 988 and logged only pre-add position-chain inputs, index and base. The frozen private JSON at `build/private/phase1b-offset92-frozen.json` has SHA-256 `b1c6340eb22dfb2b4cfdb047237efbd2e36d20e5ef0742a902ad94be861cd903`. It predicts `$0C00AE=$FFC7` for marker 987 and callback-990 X/Y `$0147/$0054` for object `$0C1D00`. The input `debug.log` SHA-256 is `efdeb914fbe3983dfcfea8938e3632861bf43522e93e0bb86c60c580777585e6`; geometry CSV SHA-256 is `51ab8634160e112ceb12c15b96749a48a01f5978fc5b8cd5d6786b1bb13cce6f`.
