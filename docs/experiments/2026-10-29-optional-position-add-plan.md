# Phase 1B: optional position addition — pretarget checkpoint

**Hypothesis:** the `$034FA6–$034FB2` positive-`$80` branch adds signed `A5+$7E` to the low `D0` word before the `$034FD6` position write. **Baseline:** local `ba43f96`, the [recurrent position result](2026-10-29-position-carry-heldout-result.md), private callback-950 state, isolated MAME 0.289. **Acceptance:** hold marker-961 pre-branch `D0`, `D3`, and `$80` equal in a small development control and a larger held-out addition; freeze the predicted `$28` write and all 20 existing position-chain outputs before target replay; require exact values with branch marker and intervention configuration checked. This is a controlled private-state perturbation, not natural gameplay evidence.

**Intervention:** the optional [MAME Lua probe](../../tools/phase1b_mame_input.lua) parameter `PDRIFT_POSITION_OPTIONAL_ADD=XXXX` writes `A5+$80=1` and `A5+$7E=XXXX` once at callback 960 after loading the private state. It validates the RAM writes and prints the old/new words. The hook is restricted to the existing `position_chain` debugger mode; without the parameter, earlier experiments are unchanged. The first ensuing position update enters the branch once, decrements `$80`, and consumes `$7E`. The input-only mode does not log the post-write operand.

**Development control — verified by execution:** with steering pulse 212 and addend `$0001`, the input-only trace had marker-961 pre-branch `D0=$FF9600C1`, `D3=$00000000`, `$80=$0001`, `$7E=$0001`. The independent target-only run wrote `$28=$00C2`. The reused [position-chain model](../../tools/phase1b_position_chain_predict.py), checked by the [optional-add wrapper](../../tools/phase1b_optional_add_predict.py), matched **60/60** operand/coefficient/adjusted fields across 20 updates. This development output is not counted as held-out validation.

**Pretarget checkpoint — verified by execution:** the `$0040` input-only trace has the **same** marker-961 pre-branch `D0=$FF9600C1`, `D3=$00000000`, `$80=$0001`, but `$7E=$0040`. It enters the branch only at marker 961. The frozen private JSON `build/private/phase1b-optional212-frozen.json` has SHA-256 `53e76f82011c2ae89ed5f2a783b26d06e1801ad966ba911f8efa9931ae76f385` and predicts first `$28=$0101`, exactly `$003F` above the development-control output. It also freezes all 20 position-chain operand, ROM coefficient and adjusted-position fields. **No `$0040` target output had been opened at this checkpoint.** Its input debugger log SHA-256 is `b093a5358250ddc8cec804ec0768700ac7eb3e94a3b5fda3b25ddfdf9c37b8f2`; control log SHA-256 is `5fa79732f870b2cda08f5d14766156eee8c168eca87362d460c607260ff36c8a`.
