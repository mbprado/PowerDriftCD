# Phase 1B: matched-PC projection divisor — pretarget checkpoint

**Hypothesis:** the main-CPU projection checks its signed 16-bit raw divisor at `$033E00` before adding `$0080`. The old [projection replay](../../tools/phase1b_projection_replay.py) applied the bias first, causing the [late road-record gate failure](2026-10-29-scalar-to-road-record-result.md) to predict a projection when MAME skipped it. From actual entry-stage source, translation and coefficient words, the corrected fixed-point arithmetic should predict the `$033E00` `D2` word and whether execution reaches `$033E04`.

**Baseline and acceptance:** source revision `3bfa8c4` on `experiment/perspective-road`; pulse 56 from the private callback-950 saved state, object `$0C1D00`, odd markers 961–999. Freeze 20 signed divisors and 20 accept/skip decisions before opening target outputs. Three independent output-only MAME runs must each match **40/40** fields, including at least one accepted and one rejected gate. A failure remains a failure; the frozen JSON must not be edited. This is a gate-arithmetic test, not a complete road record or screen prediction.
