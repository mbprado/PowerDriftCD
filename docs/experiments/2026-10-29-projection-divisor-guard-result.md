# Phase 1B: matched-PC projection divisor and guard — 2026-10-29

**Result — PASS, verified by execution in MAME 0.289.** The [pretarget checkpoint](2026-10-29-projection-divisor-guard-plan.md), committed as `9c003c7`, froze 20 pulse-56 raw divisors and accept/skip decisions before target output capture. Three independent output-only MAME runs each matched **40/40 fields**, for **120/120** exact comparisons with no errors. The model predicted 17 accepted gates and three rejected gates; the rejected marker-995/997/999 raw divisors were `$FFE0/$FF4C/$FEE4`. All target debugger logs were byte-identical, SHA-256 `33a2a95daf3aea74c06d8776427838492e3d88aaf24c0775d17bbcc1a180f55f`.

**Verified by execution, cause of the late false projection:** the main-CPU code forms a signed divisor in `D2` at `$033E00` and checks its sign before adding `$0080`. The previous [projection replay](../../tools/phase1b_projection_replay.py) had checked after adding `$0080`. For the earlier pulse-212 marker 995, the actual raw divisor was `$FF9A` (−102). Adding `$0080` first yielded positive `$001A`, which made the old replay invent a projection that the arcade code skipped. The corrected replay returns no new projection for that captured callback-994 input. It still passes the existing center/left/right regression: **180/180** prior coordinate pairs and the accompanying source/geometry checks. This resolves the immediate arithmetic error in the *late* frozen road-record gate; it does not retroactively turn that gate into a held-out success.

**Method:** the input-only probe logged object `$0C1D00` source words, global translation and angle-table coefficient words at `$033D98`, after the earlier entry gate but before the multiplier arithmetic. It did not log `D2` or branch outcomes. The predictor applied signed 16-bit wrap, signed 32-bit products and the observed right shifts to calculate the raw divisor. The separate target probe logged `D2` at `$033E00` and whether execution reached `$033E04`. Exact marker alignment was required at odd markers 961–999. Input and target used the same callback-950 saved state and pulse-56 input schedule. The target runs executed MAME independently; cache hits were not counted as repetitions.
