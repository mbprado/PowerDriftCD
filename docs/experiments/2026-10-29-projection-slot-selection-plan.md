# Phase 1B: projection list-slot selection — pretarget checkpoint

**Hypothesis:** for main-CPU object `$0C1D00`, the successful-copy path uses the current `$0CFCF0` list count as a 16-byte record index and `$0CFE08` as the active list base. The record starts at `base + (count << 4)`. When this object does not reach the pre-copy stage, it makes no copy. This test predicts the local list slot and effective address from state captured at `$033E68`, before the list lock/count read and copy at `$033E8E`. It does **not** predict the count or active buffer base from still-earlier game state.

**Baseline and acceptance:** source revision `9eeb140`, branch `experiment/perspective-road`; held-out steering pulse 116 from the owner-private callback-950 state. The input-only run captures the pre-copy count/base and no target slot/address. Freeze presence or absence at all 20 odd markers 961–999, plus count, base, slot and address for every expected copy. Three fresh output-only MAME runs must match all **84 fields** each (20 decisions plus 16 × 4 fields); no cache hit counts as a repetition. Preserve the frozen JSON if a target fails.
