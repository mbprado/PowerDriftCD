# Phase 1B: stateful object projection and copy — pretarget checkpoint

**Hypothesis:** for main-CPU object `$0C1D00`, a valid `$033E00` divisor produces new X/Y; a nonpositive divisor leaves the prior X/Y unchanged. At a successful `$033E8E` copy, the shared-list record receives the current X/Y pair and the immediately prior pair. This test predicts coordinate *values and copy events*; it does not predict the variable list-slot address.

**Baseline and acceptance:** source baseline `2755692` on `experiment/perspective-road`; new held-out steering pulse 72 from the private callback-950 state. Freeze all 20 odd-marker X/Y words, 20 copy/no-copy decisions, and both pairs for every predicted copy before observing target outputs. Three independent output-only MAME runs should match every frozen field, including three negative-divisor carry steps. A failed field remains a failure; the private frozen JSON is immutable for this test.

**Method:** the input-only probe logs `$0C1D00`'s initial X/Y at callback 960 and the source, global and coefficient words at `$033D98` on markers 961–999. It does not log target object X/Y, copy events or shared-list bytes. The model reuses the corrected [projection replay](../../tools/phase1b_projection_replay.py), carrying the last X/Y when it returns no projection. On accepted updates it predicts a copy with current and prior coordinate pairs. In the output-only probe, `$033E9A` records final object X/Y; `$033E8E` records the object pairs and the just-written shared-list words at the CPU-selected slot. The slot is reported as observed provenance and is not scored as a predicted field.

**Verified by execution, input-only and development controls:** the input directory `build/private/phase1b-projection-stateful72-input/` contains 20 entries at the expected markers and no target output events. Initial X/Y were `$000A/$0019`. Its debugger and stdout SHA-256 values are `37edbec3c0059a21e6c52dae5eccee02638df82a79468c6ac2901030d409c523` and `1a33b444d7054e5e88036f670f0590c7ee575f32ca080544df97780b2a270b14`. A separate pulse-212 development run verified that the output probe can read both pairs from the object and actual shared memory after `$033E8E`; its debugger SHA-256 was `b94a93d4bfbe2e71d191d99732366d397e49e39f05530ea4fee016768d0a9caf`. That development run showed a list-slot change, reinforcing the decision to leave slot selection open. No pulse-72 target output was opened.
