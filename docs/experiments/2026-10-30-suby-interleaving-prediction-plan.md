# Phase 1B: Sub-Y entry state → list-copy count — pretarget checkpoint

**Hypothesis:** a Sub-Y execution-state signature sampled when main-CPU object `$0C1D00` enters `$033D1E` can predict whether Sub-Y inserts one shared-list record before main acquires the lock. This is a bounded **five-update signature test**, not a general scheduler model. The frozen predictions are count deltas `[+1,+1,0,0,+1]` for markers 961, 963, 965, 967 and 969 on held-out steering pulse 132. Adding each delta to the input-only entry count predicts the main locked count and 16-byte copy slot.

**Baseline and acceptance:** branch `experiment/perspective-road`, source baseline `3c4e904`; owner-private callback-950 state. The pulse-132 input-only capture reads Sub-Y's **CPU-local** `CURPC`, object pointer and two object fields through MAME Lua when main fetches the target entry instruction. It reads the shared count and lock at that entry but logs no later main lock/copy values. Three independent output-only MAME 0.289 runs should each match five entry-count controls and 15 predicted locked-count, copy-count and slot fields: **20/20 comparisons per run**. Preserve the private frozen JSON unchanged after target capture; a mismatch is a failure.

**Development basis — verified by execution, limited scope:** pulse 124 produced five paired entry states and outcomes: `$012B3A→+1`, `$012A06→+1`, `$01293E→0`, `$0129BA→0`, `$0129A8→+1`. The development input and output debugger/control evidence remains private. The pulse-132 input has a **new** fifth PC `$012932`, object `$FFFF2240` and nonzero object field `$0C=$07E0`; private Sub-Y disassembly (SHA-256 `db6698caced36c17d573eecd6ca95c1f5867e2809958ed1955807e8653291e12`) shows this branch calls the `$0129A8` projection path when that field is nonzero. Predicting that it reaches the list copy before main does is an explicit timing **hypothesis**, not proven by that branch alone. The other four PC signatures reuse the development mapping. Unknown PCs cause the predictor to stop rather than silently classify them.
